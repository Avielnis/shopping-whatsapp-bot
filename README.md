# רשימת קניות בוואטסאפ

בוט וואטסאפ אישי לרשימת קניות משותפת, בעברית. הבוט מתחבר לוואטסאפ שלך כמכשיר מקושר (כמו וואטסאפ ווב) ומגיב בצ'אט משותף (למשל קבוצה איתך ועם אשתך).

## מבנה

- `core/` — כל הלוגיקה (פרסור פקודות, ניהול הרשימה, פורמט תשובות). לא תלוי בוואטסאפ בכלל.
- `frontends/whatsapp_client.py` — המודול היחיד שתלוי ב-`neonize`. מסנן הודעות רק מהצ'אט המורשה, ומעביר טקסט ל-`core`.
- `frontends/web_admin.py` — דף ניהול מקומי (Flask, פורט 8080) לצפייה בסטטוס ועריכת הקונפיגורציה. ברשת הבית בלבד.
- `frontends/list_page.py` — דף רשימה נעים לשימוש בטלפון (Flask, פורט 8081), עיצוב כהה, מיועד לסימון מוצרים תוך כדי קניות. זה הדף שחשוף גם דרך המנהרה הציבורית.
- `frontends/cloudflare_tunnel.py` — מפעיל מנהרת Cloudflare חינמית כדי שדף הרשימה יהיה נגיש גם מחוץ לבית.
- `main.py` — מחבר את הכול ומריץ: וואטסאפ, שני דפי הווב, והמנהרה.

כדי להחליף את וואטסאפ בפרונט אחר (טלגרם, ווב) — כותבים מודול `frontends` חדש; `core` לא משתנה.

## פקודות

| פקודה | פעולה |
|---|---|
| טקסט חופשי (מוצרים מופרדים בפסיק/רווח/שורה) | הוספה לרשימה |
| `מחק <מוצר>` | מחיקת מוצר מהרשימה |
| `רשימה` | הצגת הרשימה המלאה |
| `סמן <מוצר>` | סימון מוצר כנאסף |
| `בטל סימון <מוצר>` | ביטול סימון |
| `נקה` / `מחק הכל` | ניקוי הרשימה כולה |
| `אתר הרשימה` | קבלת הקישור לדף הרשימה בלבד |
| `עזרה` | הצגת רשימת הפקודות |

כל תגובה של הבוט מסתיימת גם בקישור לדף הרשימה, אם המנהרה הציבורית פעילה.

## הרצה מקומית (בדיקות ופיתוח, על המחשב)

```bash
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r requirements.txt
cp .env.example .env

pytest                          # בדיקות הליבה, בלי וואטסאפ בכלל
```

## הרצת הבוט בפועל

1. `python main.py` — בהרצה ראשונה יודפס קוד QR בטרמינל. סרוק אותו מהטלפון שלך: וואטסאפ → הגדרות → מכשירים מקושרים → קישור מכשיר. (הבוט רץ תחת המספר שלך, כי אין מספר שני זמין — לכן ההודעות שהוא שולח יופיעו כאילו נשלחו ממך.)
2. שלח הודעת בדיקה כלשהי בצ'אט/קבוצה שבו תרצה שהבוט יפעל (מומלץ ליצור קבוצה קטנה "רשימת קניות" איתך ועם אשתך).
3. בלוגים של הבוט תראה שורה `צ'אט זוהה: ...` עם ה-JID של אותו צ'אט. העתק אותו לתוך `.env` בתור `ALLOWED_CHAT_JID`.
4. הפעל מחדש את `main.py`. מעכשיו הבוט מגיב רק בצ'אט הזה, ומתעלם מכל השאר.

הסשן של וואטסאפ (הפיירינג) נשמר בקובץ `data/session.db` — לא צריך לסרוק שוב בכל הרצה.

## שני דפי הווב

**דף ניהול** (`http://<כתובת-הפיי>:8080`, ברשת הבית בלבד — לא חשוף לאינטרנט): סטטוס חיבור (כולל קוד QR לסריקה אם צריך לחבר מחדש — בלי לפתוח טרמינל), עריכת הרשימה, לוגים חיים, והקונפיגורציה (כולל רשימת צ'אטים שזוהו לאחרונה, לבחירת `ALLOWED_CHAT_JID` בלי לחפש בלוגים). "Save & restart" שומר ל-`.env` **ומאתחל את הראזפברי פיי**.

**דף רשימה** (`http://<כתובת-הפיי>:8081`): עיצוב כהה ונוח לטלפון, מיועד לשימוש תוך כדי קניות — לסמן מוצרים (הם יורדים אוטומטית לתחתית הרשימה) ולהוסיף מוצרים ששכחתם. זה הדף שחשוף גם דרך המנהרה הציבורית ומופיע כקישור בכל תגובה של הבוט (ובתגובה לפקודת `אתר הרשימה`). שני הדפים קוראים וכותבים לאותה רשימה בזמן אמת.

אתחול הפיי מתוך הבוט דורש הרשאה חד-פעמית בפיי (ראה בהמשך). שני הפורטים (8080, 8081) אינם פורטים מוגנים ולכן אינם דורשים הרשאות מיוחדות.

### גישה מכל מקום (לא רק ברשת הבית)

הבוט מפעיל אוטומטית מנהרת [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) חינמית (`cloudflared`) שמפרסמת את **דף הרשימה** (פורט 8081, לא דף הניהול) בכתובת ציבורית — אותו עיקרון כמו הבוט עצמו: הפיי רק פותח חיבור יוצא, בלי הפניית פורטים ובלי לחשוף את הרשת שלך. הקישור מופיע בסוף כל תגובה של הבוט בוואטסאפ, בפקודת `אתר הרשימה`, ובדף הניהול.

⚠️ **הקישור פתוח לכל מי שמקבל אותו** (לא ביקשת סיסמה, אז לא הוספתי) — כל מי שיש לו את הקישור יכול לצפות/לערוך את הרשימה. שמרו עליו כמו סיסמה. (דף הניהול, עם יכולת האתחול, לא נחשף דרך המנהרה — נשאר ברשת הבית בלבד.)

⚠️ מכיוון שזו "מנהרה חינמית" בלי דומיין קבוע, **הכתובת משתנה בכל הפעלה מחדש** של הבוט (למשל אחרי אתחול הפיי). תמיד אפשר לקבל את הכתובת העדכנית ע"י שליחת `אתר הרשימה` בוואטסאפ.

התקנת `cloudflared` על הפיי (חד-פעמי):
```bash
sudo mkdir -p --mode=0755 /usr/share/keyrings
curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
echo 'deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main' | sudo tee /etc/apt/sources.list.d/cloudflared.list
sudo apt-get update && sudo apt-get install cloudflared
```
אם `cloudflared` לא מותקן, הבוט ממשיך לעבוד כרגיל (כולל וואטסאפ ודף הניהול המקומי) — פשוט בלי קישור ציבורי.

## מעבר לראזפברי פיי

1. העתק את כל התיקייה (או `git clone`) לפיי, ואת תיקיית `data/` מהמחשב (כדי לשמר את הפיירינג בלי לסרוק שוב).
2. `python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt`
   - `neonize` עוטף ליבה בשפת Go — ודא שההתקנה מצליחה על ה-Raspberry Pi OS (aarch64) לפני שממשיכים; אם אין wheel מוכן ייתכן שיהיה צורך להתקין Go ולבנות מקור.
3. הרשאה חד-פעמית שדף הניהול צריך כדי לאתחל את הפיי (הבוט עצמו רץ כמשתמש רגיל, לא root):
   ```bash
   echo "$(whoami) ALL=NOPASSWD: /sbin/reboot" | sudo tee /etc/sudoers.d/shopping-bot-reboot
   ```
4. התקנת שירות `systemd` להרצה קבועה:
   ```bash
   sudo cp deploy/shopping-bot.service /etc/systemd/system/
   sudo systemctl enable --now shopping-bot
   ```
5. `journalctl -u shopping-bot -f` למעקב אחר הלוגים.
